Creating a class student by student takes an evening. Importing the ministry workbook takes a minute — and Nuktah already knows its layout.

## 1. Start from the import screen

Choose Import and pick your original ministry file — `.xlsx` or `.xls`. No conversion step needed: use the workbook you already keep for the class.

## 2. Columns are detected for you

Nuktah looks for the header row and matches columns by their French, Arabic or coded labels — student name, matricule, and the grade columns. Every student row with a numeric matricule becomes a student in the class.

**The matricule is the key.** Names may repeat or change; the registration number never does. Everything that follows — scanning, matching, updating — relies on it.

## 3. Your first import is free

Every new account starts with two scans and one import. The import credit is spent once, after the file is accepted — not while you are still on the screen.

## 4. If the import fails

Two checks cover almost every failure:

- The file follows the ministry template — same columns, header row present.
- The ID column contains **numbers**, not text like “12/A” or digits split by spaces.

Fix whichever applies and import again. Still failing? Email the file name to noonnuktah@gmail.com.

## 5. Your original file stays the source of truth

Nuktah stores your workbook exactly as uploaded and only ever writes grade cells back into it — headers, formatting and structure are never rewritten. Keep a backup outside the app as well: a copy on a cloud drive protects you from a lost phone, not just a bad import.

## What comes next

Import once, then scan the paper sheet after each test: rows are matched by matricule on the review screen, and the class report is ready to export as a PDF.
