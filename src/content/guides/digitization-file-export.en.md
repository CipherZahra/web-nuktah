The digitization file is where your marks go digital: instead of living only on paper, they are recorded in a file you can export whenever you need. Nuktah reads, records and exports — your original file stays as it is.

## 1. What is the digitization file?

The file where student marks are saved as data instead of paper. Nuktah supports exporting your marks straight to it, alongside Excel and PDF. Your original ministry file stays untouched — digitization is an addition, not a replacement.

## 2. Record marks in Nuktah

Two ways:

- **Scan the sheet**: photograph the handwritten grade sheet — marks are extracted and matched to each matricule. Needs an internet connection; the scan credit is spent only after a successful read.
- **Manual entry**: type the marks on the keypad after recording absences — always free.

## 3. Review by matricule

Before saving, the review screen shows every mark next to its owner's registration number. A name can repeat or be spelled differently; the matricule is fixed for every student — so no mark lands in the wrong place.

## 4. Export to the digitization file

From your gradebook choose export: **the digitization file**, **Excel**, or **PDF**. An export costs one credit and credits never expire. Re-export after every period you close, and keep your original file safe where it is.

## 5. Quick questions

- **Does this modify my original ministry file?** No — import reads from it; exports create new outputs.
- **When should I export?** After every period that closes, or whenever a class report is needed.
- **Can I review before saving?** Always — nothing is saved until the review screen is confirmed.
